# 相叶雅纪经纪人模拟器 · 镜头之外

一场关于工作、选择与默契的中文互动故事，适配手机和电脑。

从第一章开始，点击 A/B/C/D 选项卡推进剧情，也可以在菜单中直接体验第三章咖啡店的户外企划调整。

## 游戏内容

- 三章剧情：行程与礼物准备、节目录制中的意外、午休与户外企划调整。
- 可点击的剧情分支、四项状态与五种结局。
- 相叶雅纪人物卡和对话头像，以及四张可放大的场景配图。
- 手动存档、导入与导出进度、重新开始。

游戏不会自动保存或记录完整的选择历史。手动存档仅保留在玩家自己的浏览器或导出文件中。

## 打开方式

开启 GitHub Pages 后，可通过仓库的 Pages 链接直接游玩。也可以下载 `index.html`，用现代浏览器打开。

页面无需安装依赖或执行构建。四张 AI 摄影风格场景配图已内嵌；公开人物照需要联网加载，图片加载失败不会影响游玩。

## 剧情与配图说明

本作根据一段虚构的经纪人模拟对话改编，补充了衔接与分支结局。所有剧情均属虚构，与真实人物的工作及私人生活无关；本作为非官方互动故事。

人物宣传照来源见游戏内“照片与配图”，图片权益归原权利人所有。四张场景配图由 AI 生成，并非真实录制或人物活动照片。
